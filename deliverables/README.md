## 3. 关键结论

1. **定金只算一次**：尾款 = 价格 − 定金 − 贷款；Case C/D 都把定金算了两次，ROI 因此偏差 15–60 个百分点。
2. **贷款只有一个真相**：月供、利息、本金、余额、赎回必须来自同一张摊销表；银行 settlement 优先。
3. **ROI 至少两个分母**：总成本 ROI 与现金 ROI 同时显示；Case A 是 13.6% vs 158.7%，Case C 是 6.1% vs 176.2%。
4. **法定费用可以自动算，报价总额不能硬抄**：S&P 1.6M 的法定两项是 65,250，报价总额 77,487，差额 12,237 是未列明的 SST/杂费。
5. **第一页 23 个字段够用，但要给 3 个字段加“展开”**：Monthly Holding Expenses、Other Costs、RPGT；门牌税、地税、管理费、保险、维修、retention 都放进去。
6. **v1 是个人买卖**：不做投资人分账；持有 1–5 年逐年预测；贷款默认等额本息（和中国银行一样）。

## 4. v1.1 范围（10/19 已确认）

- **两用**：给买家看买入成本清单；给卖家/中介算卖出利润。个人买入 → 持有 1–5 年 → 卖出。
- **等额本息**：月供 = P×r/(1−(1+r)^−n)，r = 年利率/12；利息按剩余本金计。
- **不做**：投资人分账、电子签、App（App 最后才打包上架）。
- **路线**：先 Web 部署到自己的深圳服务器 → 自己用 → 团队内测 → 无 bug 推广 SaaS（RM50/年）。
- **后期**：AI 助理接入（ChatGPT/个人助理，把你的行业思维写进去）、两人买家律师费、daily rest。
