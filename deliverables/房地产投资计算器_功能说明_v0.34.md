# 房地产投资计算器 · 功能说明（v0.34）

> 网址：**https://kwongthye.com** （手机、电脑都能开，免费，无需注册）
> 版本：v0.34 · 2026-10-24 · 中英文可切换（右上角 EN / 中文）
> 说明：这是一个**估算工具**，帮你快速判断一套房子「买、持有、卖出」划不划算；最终金额以律师、银行、LHDN 为准。

---

## 一、它能帮你算什么

输入一套房子的资料，自动算出：

1. **买入要出多少钱**（首付 + 律师费 + 印花税 + 估价费 + 中介费 + 杂费）
2. **每年持有要花多少钱**（管理费、地税、门牌税、维修、保险、出租中介费 + 银行利息）
3. **两种投资回报**
   - 不卖、只出租：每年租金净赚多少、回报率多少
   - 卖掉：出售利润、出售回报率、总投资回报率、总成本回报率

## 二、三个部分（Part 1 / 2 / 3）

### Part 1 · 买入费用（买房初期要出的钱）

| 你填 | 系统自动算 |
| :--- | :--- |
| SPA 价格、实际买价 | SPA 律师费（律师费 + 印花税 + 杂费 + 8% SST） |
| 贷款数额（可填 % 自动换算） | Loan Agreement 律师费（同上） |
| 年利率、贷款年限 | 房产估价费（SPA × 0.2% + 500） |
| 中介费、Consent、其他杂费 | 月供（等额本息，和中国银行一样） |
| | **Total Acquisition Costs 总购置费用** |
| | **Down Payment 首付款** |
| | **Less: Cashback 超额贷款所得（负数）** |
| | **Total Upfront Cash Required 购房所需现金总额** |

> 律师费、估价费可以**手动改**（改完变橙色），清空就恢复自动计算——因为每家律师报价不同。

### Part 2 · 每年持有费用

管理费、地税、门牌税、装修/维修、保险、出租中介费（全部自己填）；
**每月银行利息自动算**（贷款 × 年利率 ÷ 12，平均口径）。

### Part 3 · 投资回报（Investment Returns）

**① Keep & Rent 持有出租**

| 项目 | 公式 |
| :--- | :--- |
| Annual Rental Income 年租金收入 | 自己填 |
| Annual Rental Profit 年租金净利润 | 租金 − 年度费用（含利息） |
| Annual Rental Return 年租金回报率 | 年租金净利润 ÷ 购房所需现金总额 |
| Total Rental Profit 总年租金净利润 | 年租金净利润 × 年数 |

**② Sell Property 出售房产**

| 项目 | 公式 |
| :--- | :--- |
| Gross Capital Gain 出售资本收益 | 预计卖价 − 实际成交价 − 总购置费用 |
| RPGT 产业盈利税 | （卖价 − 实价 − 总购置费用 − 卖出中介费 − 卖出律师费 − 售出杂费）× 年限税率；3 年内 30%、第 4 年 20%、第 5 年 15%、第 6 年起 0% |
| Total Selling Costs 出售总费用 | 卖出中介费 + 卖出律师费 + 售出杂费 + RPGT |
| Selling Profit 出售利润 | 出售资本收益 − 出售总费用 |
| Selling Return 出售回报率 | 出售利润 ÷ 购房所需现金总额 ÷ 年数 |
| Net Investment Profit 投资净利润 | 总年租金净利润 + 出售利润 |
| Total ROI 总投资回报率 | 投资净利润 ÷ 购房所需现金总额 ÷ 年数 |
| Total Cost 总成本 | 实际成交价 + 总购置费用 + 出售总费用 |
| Return on Total Cost 总成本回报率 | 投资净利润 ÷ Total Cost ÷ 年数 |

## 三、这一版新增的实用功能

### 1. 方案存档（多套房对比）

- 顶部「方案名称」填名字 → **💾 保存方案**
- 下拉选已存方案 → **加载 / 删除**
- 同一名字再保存会覆盖更新
- 存在你自己手机/电脑的浏览器里，不上传服务器

### 2. 一键分享给客户

- 点 **🔗 复制分享链接**，把链接发给客户（WhatsApp / 微信都行）
- 客户打开看到完整计算，但**不能改**（只读，适合展示）
- 客户点「在我这边继续编辑」就能自己改
- 另有 WhatsApp / 微信 / Facebook 分享按钮（对外的数字自动带上链接）

### 3. 导出 / 导入 JSON（换设备、防丢失）

- **导出 JSON**：下载一份包含全部输入的文件
- **导入 JSON**：在新手机/新浏览器打开网站 → 导入 → 全部还原
- 换域名（以后迁到 calc.kwongthye.com）前，记得先导出

### 4. 公司抬头 + 正式 PDF

展开「公司抬头（打印用）」填写（按马来西亚习惯）：

- 公司 / 中介公司（Sdn Bhd 或 Enterprise）
- 中介姓名 + REN 编号（可选）
- 电话 / WhatsApp（+60 格式）
- 电邮、公司地址（可选）
- 客户姓名、项目 / 楼盘

点 **🖨️ 导出 PDF / 打印**：

- **第 1 页**：公司抬头（Logo + 公司名 + 联系方式 + 客户名 + 日期 + **分享链接二维码**）+ Part 1 买入费用
- **第 2 页**：Part 2 年度费用 + Part 3 投资回报
- 手机上选「存储为 PDF」即可发给客户

### 5. 其它

- 中英文一键切换
- 金额自动按西方格式显示：500,000.00
- 手机适配，随时能算

## 四、怎么用（5 步）

1. 打开 **https://kwongthye.com**
2. 填 SPA 价、实际买价、贷款、利率、年限（点「填入示例」可先看一套样板）
3. 填租金、卖价、持有年限
4. 看 Part 3 的两个回报率（出租 / 卖出）
5. 点「保存方案」存档，或「导出 PDF」发给客户

---

## 五、要注意的几点

1. **数字是估算**：律师费按法定费率自动算，但律师实际报价可能不同；RPGT 用的是「老板口径」（卖价 − 各项成本 × 年限税率），不是 LHDN 法定算法，报税前请找会计师确认
2. **利息是平均口径**：贷款 × 年利率 ÷ 12；真实等额本息每月利息会随余额略减，以银行账单为准
3. **存档只在本机**：换手机/换浏览器看不到旧存档，请用「导出 / 导入 JSON」
4. **只读分享不含隐私**：链接里包含计算数字，发给客户前确认没有敏感备注（目前没有备注字段）
5. 本工具不构成法律、税务或投资建议
