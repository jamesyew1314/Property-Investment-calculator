# 房地产投资分析系统 — 方案摘要与确认单 v1.1

> 给中介用的**快速计算程序**：一间房，个人买入 → 持有 1–5 年 → 卖出，最短时间算出**一共花多少钱、最后赚多少钱**。
> 本文档是 57 页完整方案的浓缩版，用于给合伙人/朋友确认。确认后即可开工。

---

## 1. 这个程序是干什么的

**两用：**

| 用途 | 页面 | 回答什么 |
| :--- | :--- | :--- |
| ① 给买家 | 买入成本清单 | 这间房买下来一共要花多少钱（实价 + 律师费 + 印花税 + SST + 估值 + agent + 装修）；首付要准备多少现金；月供多少 |
| ② 给卖家 / 中介 | 卖出利润 | 卖出去扣掉所有费用（赎回贷款 + agent 佣金 + 律师费 + RPGT），最后赚多少 |

**核心就一句话：** `净利润 = 卖出净收入 + 租金收入 − 月供 − 持有费用 − 买入总成本`

---

## 2. 计算分 3 个 Part（你定的结构）

**Part 1 · 买入（第一次要出的费用）**

| 字段 | 怎么填 |
| :--- | :--- |
| SPA 价格、实际买价、贷款数额 | 自己填 |
| 利率（年限默认 30 年，可改） | 自己填 → **月供自动算** |
| SPA 律师费 | 自动跟着 SPA 价格算（律师费 + 印花税 + 杂费 + 8% SST；杂费 100k 起 4,000，每多 100k +400） |
| Loan Agreement 律师费 | 自动跟着贷款数额算（律师费 + 贷款印花税 0.5% + 杂费 + 8% SST；杂费 100k 起 4,000，每多 100k +200） |
| 估价费 | 自动跟着 SPA 价格算（SPA × 0.2% + 500 杂费） |
| Agent Fee、Consent Fee（如有）、其他费用 | 自己填 |

→ **Total Acquisition Costs 总购置费用**（SPA 律师费 + LA 律师费 + 估价费 + 中介费 + 其他）→ **Down Payment 首付款** → **Less: Cashback** → **Total Upfront Cash Required 购房所需现金总额**

**Part 2 · 年度费用（全部自己填，只有一个自动）**

| 字段 | 怎么填 |
| :--- | :--- |
| Management Fee、地税、门牌税、装修/维修、出租中介费（每年 RM） | 自己填 |
| 每个月银行利息 | 自动（等额本息，和中国银行一样） |
| （展开）保险 | 自己填，可选 |
| （展开）卖出律师费、RPGT | 自动（RPGT 按持有年 30/20/15/0） |

→ **每年总费用（自动）**

**Part 3 · Investment Returns（投资回报分析：先看持有，再看卖出）**

| 字段 | 怎么填 |
| :--- | :--- |
| ① Keep & Rent：Annual Rental Income 年租金收入 | 自己填 |
| ② Sell Property：Expected Selling Price 预计卖出价格、Holding Period 持有年限、Agent Fee 卖出中介费（金额格，默认 = 卖价 × 2%，可手改金额）、Legal Fee 律师费、Selling Miscellaneous Expenses 售出杂费；自动带出 Total Upfront Cash Required、Actual Purchase Price、Total Acquisition Costs → Gross Capital Gain → Total Selling Costs（中介+律师+杂费+RPGT）；RPGT =（卖价 − 实价 − 总购置费用 − 卖出中介费 − 卖出律师费 − 售出杂费）× 年限税率（30/20/15/0）→ Total Selling Costs → Selling Profit → Selling Return → Net Investment Profit（①+②）→ Total ROI → Total Cost → Return on Total Cost | 自己填 + 自动连接 Part 1 |

→ **① Annual Rental Return 年租金回报率（自动）=（Annual Rental Income 年租金收入 − Part 2 年度费用含利息）÷ 购房所需现金总额**；**Total Rental Profit 总年租金净利润 = 年租金净利润 × 年数**
→ **② 卖出利润（自动）**：年利润 = 净赚（卖价 − 买进总费用）÷ 自己现金 ÷ 年数；旁边再给“扣所有费用”的完整算法（月供利息、卖出中介/律师费、RPGT）做对照。

例（SPA 1M / 实价 800k / 贷 800k / 租金 5,000×12 / 一年后卖 900k）：持有年利润 ≈36.97%；卖出年利润（快速口径）≈52.35%。

例（720k / 4.5% / 30 年 / 月租 4,500）：

| 年份 | 年末贷款余额 | 累计还本 | 累计租金 | RPGT |
| :--- | ---: | ---: | ---: | :---: |
| 第 1 年 | 708,384.82 | 11,615.18 | 54,000 | 30% |
| 第 2 年 | 696,236.04 | 23,763.96 | 108,000 | 30% |
| 第 3 年 | 683,529.15 | 36,470.85 | 162,000 | 30% |
| 第 4 年 | 670,238.50 | 49,761.50 | 216,000 | 20% |
| 第 5 年 | 656,337.29 | 63,662.71 | 270,000 | 15% |

另外两条原则：**回报数字写清楚**（现金回报率 + 总成本回报率 + 年化 XIRR 同时显示，不靠高杠杆把回报“看起来很高”）；**手填不到 15 个字段**——律师费、印花税、月供、每月利息、卖出律师费、RPGT、赎回余额全部自动算，60 秒出结果。

## 3. 为什么数字可信（已经验证过）

用你自己的 4 个真实案例逐行对账，发现了 Excel 里的问题并修正：

| 案例 | Excel ROI | 修正后 ROI | 原因 |
| :--- | ---: | ---: | :--- |
| A Austin Perdana | 156.32% | 158.71%\* | 预收租金按负债处理 |
| B L.T | 9.11% | 4.56% | 漏了 3,545 出售税；本金与银行余额不一致 |
| C Cashback | 114.46% | 176.17% | 定金被算了两次 |
| D Downpay | 18.66% | 20.23% | 定金被算了两次 |

\* Case A 还缺结算单，需要你提供 3 份单据后定案。

同时把律所报价单反算成公式，验证 100% 吻合；律所报价里的“打印/transport/杂费”算不到，系统只做**预测**并标注，不假装精确。

## 4. v1 范围（已经拍板）

**✅ 做：**

- 计算页分 3 个 Part：**买入一次性 → 年度费用 → 年度利润**
- 两用计算：买入成本清单 + 卖出利润
- 持有 1–5 年逐年预测（租金 + 贷款余额 + RPGT）
- 贷款等额本息（和中国银行一样）
- 律师费按单一买家预测（两人买家以后加）
- Web 网页版，手机直接用；语言 EN + 中文

**❌ 不做（v1）：**

- 投资人分账（以后需要再加）
- 电子签合同
- App（网页先跑顺，最后才打包上架）
