# 计算器利息口径修复说明

> 版本：**v0.80**（2026-10-27）
> 起因：老板发现「月供扣掉利息」与「卖出时贷款余额」对不上
> 结论：**已统一为等额本息摊还表口径，两处数字现在完全对平**

---

## 一、问题现象

以截图那笔为例：SPA 1,000,000 / 实价 800,000 / 贷款 800,000 / 利率 4.5% / 30 年

| 项目 | 修复前 | 说明 |
| :--- | ---: | :--- |
| 月供（等额本息） | RM 4,053.48 | 正确 |
| 每月银行利息（平均） | RM 3,000.00 | 贷款 800,000 × 4.5% ÷ 12 |
| 卖出时贷款余额 | RM 787,094.22 | 来自摊还表 |
| **隐含本金偿还**（月供×12 − 利息） | **RM 12,641.76** | 4,053.48×12 − 36,000 |
| **余额实际减少**（800,000 − 787,094.22） | **RM 12,905.78** | |
| **差额** | **RM 264.02** | 两套算法打架 |

---

## 二、根本原因

同一个页面里用了**两套不同的利息算法**：

| 数值 | 原来用的算法 |
| :--- | :--- |
| Part 2「每月银行利息」、Part 3「当年费用 / 当年净利润」 | **平均口径**：年利息 = 贷款 × 年利率 |
| Part 3「卖出时贷款余额」、逐年表「年末余额」 | **等额本息摊还表**：利息 = 剩余本金 × 月利率 |

平均口径忽略了「本金逐月减少」这件事，所以第一年就会高估利息约 264 元；
持有越久、利率越高，差得越多。

---

## 三、修复方案

**全部改用等额本息摊还表的真实利息**，一处计算、多处引用：

```
月利率 r = 年利率 ÷ 12
月供   P = 贷款 × r ÷ (1 − (1+r)^(−年限×12))
第 n 年利息 = Σ（每月月初剩余本金 × r）
第 n 年本金 = 12 × 月供 − 第 n 年利息
年末余额   = 年初余额 − 第 n 年本金
```

由此得到两个**恒等关系**（已写成回归测试）：

```
① 12 × 月供 = 当年利息 + 当年本金偿还
② 年初余额 − 年末余额 = 当年本金偿还
```

## 九、注意事项

1. **旧数字会小幅变化**：用旧版算过、发给客户的报告，净利润 / ROI 可能相差 ~1%，建议重新导出一份。
2. **Part 2 的「每月利息」不再是 贷款×利率÷12**：它是第 1 年的实际平均月息（本金在还，所以略低）。如果客户习惯心算，可口头说明「实际约 2,978，粗算 3,000」。
3. **RPGT、律师费、印花税、Total Cost 等口径未改动**，只改了利息分摊方式。
4. 旧副本 `laoyeshu.cn/static/fangchan/` 已停用（与本修复无关，另见关停记录）。
