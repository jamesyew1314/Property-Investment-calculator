# 竞品拆解：Jovelle Ding / EAG → PropNet 优化方案

> 调研对象：<https://www.jovelleding.com/>（个人品牌站）与 `/eag/`（EAG AI 小助理）  
> 时间：2026-11-06

---

## 一、对方做对了什么

### 1. 个人品牌页，而不是「房源列表页」

- 首屏就是人：姓名、照片位、REN、团队、14 年经验、200+ 宗、RM300M+ 成交额
- 有故事、有理念、有团队（EAG 百人团队 / 千万业绩）
- 信任三件套：**BOVAEP 注册 · REN 编号 · 团队与业绩**

### 2. 一条完整的客户漏斗

```
关于我 → 房源搜索 → 委托产业 → 贷款计算 → 产业知识 → 加入团队 → 联系我
```

- 买家：搜索房源、算月供、看知识内容
- 业主：直接「委托产业」
- 同行/新人：加入团队

### 3. 工具引流

- 贷款计算机（月供）
- 贷款批率计算机（最高可买多少）
- 收藏（♡）+ 分享（WhatsApp / Telegram / Facebook）

### 4. 内容与信任资产

- 产业知识文章 + 视频
- 客户评价（审核后展示）
- 中英双语切换

### 5. EAG AI 小助理（`/eag/`）

- Google 登录即用，降低门槛
- 定位是「团队内部 AI 助手」，不是公开工具
- 页面本身做了加密/防抄，说明他们把「AI 工作流」当核心竞争力

---

## 二、PropNet 的差距

| 能力 | 对方 | PropNet（改前） |
| :--- | :--- | :--- |
| 个人品牌页 | 完整（故事/数据/团队/评价/视频） | 只有姓名、简介、区域、房源 |
| 信任数据 | 年限、成交宗数、成交额 | 只有 REN 与「已验证」 |
| 客户漏斗 | 咨询 + 业主委托 + 加入 | 只有加入 |
| 分享 | WhatsApp / Telegram / FB / 收藏 | 无 |
| 公开房源详情 | 有 | 无（房源池要登录） |
| 工具 | 两个贷款计算器 | 计算器（外链） |
| 内容 | 文章 + 视频 | 无 |
| AI 助手 | 有（团队内部） | 无 |

## 三、已落地（v1.19）

### 1. 中介个人站升级为「品牌页」

- 首屏：头像、姓名、REN、团队、验证徽章
- **数据条**：公开房源数 / 覆盖区域数 / 入驻状态
- **两个 WhatsApp 漏斗**：「咨询中介」「业主委托」，自动带预填文案
- **分享**：复制链接、WhatsApp、Facebook
- **手机端悬浮 WhatsApp 按钮**
- 关于、专长区域、在售房源分区
- 三语（中 / EN / BM）

### 2. 新增公开房源详情页 `/p/:code`

- 业主资料不出网：只显示楼盘、区域、价格、房型、面积、产权、照片
- 货源中介卡片：姓名、团队、REN、WhatsApp、电话
- 相册缩略图切换、结构化数据（SEO）
- 个人站房源卡直接跳到公开详情，客户不用登录

### 3. 待部署

代码已完成，但服务器 SSH（22）当前拒绝连接，尚未发布。恢复后执行 `bash deploy/deploy.sh` 即可。

## 四、下一阶段建议（按优先级）

| 优先级 | 事项 | 说明 |
| :---: | :--- | :--- |
| P0 | 部署 v1.19 | SSH 恢复后立刻发 |
| P0 | 中介资料补「从业年限 / 成交宗数 / 成交额」 | 个人站数据条直接用，需加字段与编辑表单 |
| P1 | 客户评价（审核后展示） | 个人站信任资产，后台审核 |
| P1 | 业主委托表单（入库，不只 WhatsApp） | 现在只是预填消息，改成线索表 |
| P1 | 房源收藏（localStorage） | 客户可收藏，回访 |
| P2 | 贷款计算器嵌入个人站 | 复用 calc，做「月供速算」小部件 |
| P2 | 内容模块（文章/视频） | 复用现有 `lib_*` 或新表 |
| P3 | AI 小助理 | 需模型 API Key；先做「房源文案生成」最小闭环 |

## 五、结论

对方强在**把中介本人做成品牌**，PropNet 强在**同行网络与货源流转**。  
正确策略不是照抄，而是：

> 用「品牌页 + 公开详情 + WhatsApp 漏斗」承接客户，  
> 用「中心池 + 带看记录 + 分佣留痕」承接同行。

两者结合，才是对方没有的壁垒。
