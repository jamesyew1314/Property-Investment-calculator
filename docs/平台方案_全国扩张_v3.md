## 2. 市场判断：这是另一个生意

| 维度 | 柔佛（原计划） | 全马（现在） |
| :--- | :--- | :--- |
| 中介数量 | 几千 | 数万（以 LPPEH 登记为准，需核实） |
| 冷启动方式 | 1 对 1 拉人 | 必须自助注册 + 州级合伙人 |
| 竞争 | 本地小平台 | PropertyGuru / iProperty / EdgeProp / Mudah |
| 内容 | 一个新山 | 16 个州、110 个城市 |
| 客服 | 微信群 | 多语言、跨时区（西马/东马） |

**结论：不能做「又一个房源门户」。** 门户拼的是 C 端流量和广告，你拼不过 PropertyGuru。

**你的差异化只有一个：中介对中介的货源/客源网络（co-broke）。**
- 门户：帮中介找**买家**（C 端流量）
- PropNet：帮中介找**同行**（B 端网络）——谁有盘、谁有客、谁带的看、怎么分

这个定位全国通用，而且越多人用越值钱。

已定：标准 **RM89/月**，早鸟 **RM59/月锁 12 个月**，团队 **RM299/5 席**。

**待定：早鸟席位从 80 扩到多少？**

| 方案 | 早鸟席位 | 覆盖 | 12 个月让利 | 建议 |
| :--- | ---: | :--- | ---: | :--- |
| A（原） | 80 | 只够柔佛 | ~RM28,800 | 全国不够分 |

## 4. 冷启动：分三波，不要全国同时开

| 波次 | 时间 | 州属 | 目标 |
| :--- | :--- | :--- | :--- |
| **W1** | 第 1–2 月 | 柔佛 + 吉隆坡 + 雪兰莪 | 150 位中介、800 条房源（覆盖 60% 市场） |
| **W2** | 第 3–4 月 | 槟城、马六甲、森美兰、霹雳 | +150 位、+700 条 |
| **W3** | 第 5–6 月 | 沙巴、砂拉越、吉打、彭亨、其他 | +200 位、+500 条 |

每州配 **1 位城市合伙人**（当地资深中介）：
- 负责拉新、培训、审核房源
- 拿该州订阅收入的 10–15%（或固定津贴）
- 给「州合伙人」标识与优先展示

> 80 人团队先做透柔佛 + 巴生谷；其他州靠合伙人复制，不要自己跑。

## 6. 产品缺口（M1 之前必须补）

| # | 缺口 | 为什么全国化必须做 |
| :---: | :--- | :--- |
| 1 | **自助注册 + 邮箱验证** | 不可能 1 对 1 开通几万人 |
| 2 | **REN 验证**（上传名片/执照，人工审核） | 全国陌生人网络，信任是命门 |
| 3 | **马来语（BM）** | 全马中介主力语言之一，只有中英会丢掉一半市场 |
| 4 | **州/城市 SEO 页**（`/properties/kl/`） | 全国流量靠长尾搜索 |
| 5 | **在线支付**（Billplz / Stripe）+ 发票 + SST | 全国收款不能靠转账 |
| 6 | **举报/下架**（假房源、已售未撤） | 规模越大越需要治理 |
| 7 | **手机优先**（中介 90% 用手机） | 现有网页可用，但发布流程要更短 |

## 7. 风险

| 风险 | 说明 | 对策 |
| :--- | :--- | :--- |
| **打不过门户** | PropertyGuru 有 C 端流量 | 不打 C 端，打 B 端 co-broke；官网只做信任与 SEO |
| **假房源/重复** | 全国开放后必然出现 | REN 验证 + 单位唯一索引 + 举报 + 30 天未更新降权 |
| **跨州不信任** | 陌生人凭什么合作 | 货源标注 + 带看留痕 + 平台不碰钱只记录 |
| **冷启动摊薄** | 16 州同时开，每州都不够密 | 分三波，先做透两州 |
| **语言** | 只做中英丢市场 | 第二阶段上 BM |
| **PDPA** | 全国客户资料 | 默认脱敏 + 同意留痕 + 可删除 |
