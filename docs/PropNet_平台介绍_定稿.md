## 一句话

PropNet 是**只给地产中介用**的柔佛房源网络：中介把房源上传一次，同行就能在中心池找到、申请带看、合作成交；屋主资料不出网，货源永远标明是谁的。

- 官网：<https://kwongthye.com/>
- 中介工作台：<https://kwongthye.com/agent/>
- 公司业务：<https://kwongthye.com/company/>

---

## 为什么做

中介每天在重复三件事：

1. **一套房，上传十次** —— WhatsApp 群、网站、另一个群；还要人工下载再上传。
2. **货源不集中** —— 想找某个区的盘，只能翻聊天记录，不知道谁手上有。
3. **合作没记录** —— 谁带的客、谁出的盘，全靠记忆，分佣容易起争议。

PropNet 把这三件事收进一个系统：**传一次、同行找得到、合作有记录**。

## 核心流程

```
中介登录 → 上传房源（照片/价格/房型）
        → 进入中心池（同行可见）
        → 可选：公开到官网
        → 一键分享到 WhatsApp 群（标准文案 + 分享卡）
        → 同行申请带看 → 出盘中介接受 → 完成记录
```

### 1. 上传一次

工作台里录入项目、区域、价格、房型、面积、照片。  
照片自动压缩 + 缩略图 + WebP，不必自己处理。

### 2. 同行找得到

中心池按区域、预算、房型筛选；每条房源标明**货源中介 + REN + 电话**，一眼知道找谁合作。

### 3. 分享到群

一键生成标准文案与 1080×1350 分享卡，点「打开 WhatsApp」选群发送。  
不用手打，也不用每天重新上传。

### 4. 合作留痕

同行点「申请带看」，填客户姓名/电话；出盘中介收到询盘，可接受/拒绝/标记完成。  
谁带来的客，系统有记录。

## 功能清单

### 中介工作台（`/agent/`）

- 自助注册 / 登录 / 邮箱验证
- 我的房源：新增、编辑、删除、公开/收回
- 中心池：全柔佛筛选、货源中介联系方式、申请带看
- 我的客户：买家/租客需求（只有自己可见）
- 自动匹配：按预算、区域、房型、房间数给客户找货
- 带看询盘：收到 / 发出、接受 / 拒绝 / 完成
- 个人站：`kwongthye.com/a/你的名字`（对外名片，含公开房源）
- 分享到群：标准文案 + 分享卡 PNG
- 每日摘要：早上 8 点邮件推送新询盘与新匹配
- 邮件语言：中文 / English / BM 可选

### 平台侧（后台）

- 中介审核：通过 / 驳回（附原因）/ 拉黑（踢下线 + 房源收回）
- 房源与客户数据隔离（每个中介只看自己的）
- 公开范围开关（默认柔佛）
- 订阅/兑换码能力已就绪，但**前端入口暂时关闭**

---

## 三条原则

1. **只给中介**
   平台不做 C 端找房，不开放买家/卖家注册。

2. **屋主资料不出网**
   对外只出现：楼盘、区域、价格、房型、面积、照片、货源中介姓名 + REN + 电话。  
   屋主姓名、电话、门牌、备注一律不公开。

3. **货源永远署名**
   谁出的盘，系统记录；同行带客成交，分佣有据可查。
