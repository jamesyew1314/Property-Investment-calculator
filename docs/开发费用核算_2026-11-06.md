### token 统计口径

- 覆盖 2026-10-18 至 2026-11-06 的 9 个 DSH 会话、3,744 条有 usage 的 assistant 消息。
- 按消息 ID 去重：fork / 续接会话复制的历史只计一次，避免重复计费。
- 按每条消息发生时的 `model/selection` 归属模型；无选择事件的会话按系统提示中的模型名归属。
- 缓存读取按 cache-read 单价计；未缓存输入按 input 单价计；输出按 output 单价计。
- 不含 DeepSeek 网页版、其他客户端或其他工作区的用量。
