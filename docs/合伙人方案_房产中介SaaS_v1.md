# 房产中介 SaaS · 合伙人方案

**马来西亚 · 垂直订阅 · 从"计算器"到"成交工作台"**

版本 v1 · 2026-10 · 内部讨论用（含估算数字，需访谈验证）

---

## 一页纸摘要

| 项目 | 内容 |
| :--- | :--- |
| 机会 | 全马 3–4 万注册 REN、1.5–2 万活跃中介，日常还在用 Excel + WhatsApp 做投资分析、佣金和客户跟进 |
| 产品 | 把现有计算器升级为**中介的成交工作台**：单子分析 → 品牌化提案 → 分享留资 → 客户/佣金管理 → 数据 |
| 已有资产 | 可运行的计算器（3 个 Part、中英双语、PDF/打印、一键分享、48 项测试、已上线），**不是从零开始** |
| 模式 | Freemium + Pro RM 49/月 + 团队版 RM 199–499/月 + 代理公司白标 + 转介收入 |
| 3 年目标 | 付费 1,500–2,000 人，ARR **RM 100–180 万**（个人版 + 团队版），精益团队 3–6 人 |
| 12 个月目标 | 付费 500 人，ARR RM 25–30 万，验证"提案 → 成交"闭环 |
| 需要投入 | 前 3 个月 RM 8–12 万；12 个月 RM 30–50 万（1 开发 + 1 增长 + 云/设计/内容） |
| 主要风险 | 订阅天花板、中介流失高、免费替代、合规（PDPA / 专业责任）——均有对策（见第 9 节） |

**一句话**：这不是一个"卖计算器"的生意，而是一个"帮中介把单子谈成"的工具生意；先做小而美、能盈利，再谈放大。

## 1. 为什么是现在

1. **中介获客成本在涨、lead 质量在跌**：门户套餐越卖越贵，中介对"只给 lead 不给工具"的抱怨在增加（待访谈验证）。
2. **AI 与移动端把"专业提案"的门槛打下来了**：过去要请人做 PPT/Excel，现在 30 秒生成。
3. **合规数字化窗口**：LHDN e-Invoice 逐步强制，小中介需要开票/记录工具，这是"顺手做进去"的壁垒。
4. **本地语言被忽视**：门户以英文为主，BM 与中文市场的体验差，垂直工具可以赢在本地化。
5. **我们已经有产品**：计算器已上线、可持续迭代，边际开发成本极低，试错速度快。

## 2. 市场与客户

### 2.1 规模（估算，需核实）

| 指标 | 估算 |
| :--- | ---: |
| 注册 REN | 3–4 万人 |
| 活跃中介 | 1.5–2 万人 |
| 代理公司 | 2,000+ 家（多数 5–50 人） |
| 可付费人群（活跃 × 愿付费 30–40%） | 6,000–9,000 人 |
| 3 年可触及（渗透 2–5%） | 600–1,500 付费 |

### 2.2 客户画像

- 80% 个人或 5 人以下小团队；手机办公；WhatsApp 是主战场。
- 收入不稳定，但对"能带来成交"的工具，RM 50–150/月可接受。
- 语言：BM（大众）、EN（商业/高端）、中文（华人市场）——**BM 是放量关键**。

### 2.3 他们现在花什么钱

| 支出 | 量级 |
| :--- | :--- |
| 门户 lead 套餐 | 数百–数千 RM/月 |
| 培训/课程 | RM 1,000–5,000/次 |
| 名片/传单/广告 | RM 200–1,000/月 |
| 工具（CRM/表格） | 几乎为零，靠 Excel + WhatsApp |

### 2.4 痛点排序（待访谈验证）

1. 客户问"这个买得过吗"——要 1 分钟出专业分析/提案。
2. 佣金、co-broke、团队抽成、开票混乱。
3. 客户跟进无系统，忘记跟、离职带走客户。
4. 投资客要 yield/现金流/RPGT/出租管理。
5. 发给客户的文件像 Excel，不像专业顾问。

## 3. 产品：从计算器到成交工作台

### 3.1 现在就有（免费版获客）

- 3 个 Part 的完整计算：买入费用、年度持有费用、持有/出售回报（含 RPGT、律师费、印花税、估价费、XIRR）。
- 中英双语、金额千分位、自动/手动混合输入、一键打印 PDF、WhatsApp/微信/Facebook 分享。
- 48 项自动测试，数字可核对。

### 3.2 P0：能收钱的最小闭环（0–2 个月）

| 功能 | 为什么付费 |
| :--- | :--- |
| 账号 + 云端保存单子 | 换手机/换电脑不丢，手机优先 |
| **品牌化提案**（logo/头像/电话 + PDF/图片/WhatsApp 文案） | 客户觉得你专业，直接提高成交率 |
| **分享链接 + 留资** | 客户打开提案，记录看了哪页、留电话 → 线索回流（杀手功能） |
| 4 套模板（自住/投资/转售/出租） | 不同客户不同话术，省时间 |
| BM/EN/中文 | 覆盖大众市场 |
| 支付 + e-Invoice | 合规，且是续费钩子 |

### 3.3 P1：留存（2–5 个月）

- 客户 & 单子 CRM：阶段、提醒、WhatsApp 一键跟。
- 佣金账本：成交额、co-broke 分账、团队抽成、开票（SST 8%）。
- 对比模式：2–3 个单位并排比 yield/现金流/ROI。
- 贷款资格（DSR/月供承受力）、银行利率表。
- 出租模块：租约到期、租金收据、年度对账。

### 3.4 P2：护城河（5–18 个月）

- 区域成交/租金参考（comps）、AI 生成提案叙事、团队看板、白标、转介收入。
- **数据飞轮**：中介用免费工具换"真实成交价/租金"上报 → 独家数据。

### 3.5 明确不做（12 个月内）

房源门户、全功能 CRM、独立电子签、通用 AVM、放贷。理由见《SaaS商业方案》§10。

## 5. 竞争与护城河

| 对手 | 他们的强项 | 我们的位置 |
| :--- | :--- | :--- |
| PropertyGuru / iProperty / Mudah | 买家流量、房源库存、品牌 | 不做门户，做"盘源→分析→提案→成交"的流水线 |
| Brickz / DataSense | 成交数据 | 用中介贡献数据做独家 comps |
| 通用 CRM / Excel | 功能全 / 免费 | 垂直：佣金、co-broke、RPGT、提案 |
| 银行/律师计算器 | 免费 | 品牌化交付 + 客户留资 + 单子管理 |

**护城河 = 中介贡献的真实成交/租金数据 + 日常 workflow 锁定 + 团队/代理公司分销。** 门户有流量但没有成交闭环数据；通用 CRM 有流程但不懂房产。

## 8. 团队与分工

| 角色 | 职责 | 投入 |
| :--- | :--- | :--- |
| 产品 & 技术（我方） | 产品设计、开发、上线、数据 | 全职/半职 |
| 增长 & BD（合伙人） | 中介社群、培训讲师、代理公司、内容 | 半职起步 |
| 兼职设计/内容 | 落地页、案例、视频 | 外包 |

**需要合伙人带来的三样东西**：① 中介/代理公司网络（前 100 个种子用户）② 培训/讲师渠道 ③ 本地信任（BM/中文社群）。

**股权/分配框架（示例，待谈，需律师定稿）**：创始人 60–70%、合伙人 20–30%、ESOP 10%；vesting 4 年、1 年 cliff；按"资金 + 时间 + 资源"折算。

## 9. 风险与对策

| 风险 | 影响 | 对策 |
| :--- | :--- | :--- |
| 订阅天花板（RM 200 万级） | 增长受限 | 团队版/白标/转介；12 个月后评估出海 |
| 中介流失高、兼职多 | 续费差 | 年付、把工具嵌进日常（CRM/佣金/租约）、团队版锁定 |
| 免费替代 / 门户跟进 | 付费意愿低 | 速度 + 垂直深度 + 交付闭环 + 本地语言 |
| 付费转化低 | 现金流 | 30 天退款、早鸟锁价、案例驱动 |
| PDPA / 专业责任 | 法律风险 | 数据加密与删除权、全程"估算"免责、不给保证回报 |
| 合伙分歧 | 执行风险 | 股权 vesting、书面分工、季度复盘、止损线 |

**止损线**：6 个月付费 <50 或周活跃/注册 <25% → 停下重估，不再追加投入。

## 10. 需要一起决定的三件事

1. **做不做**：这是"精益现金流生意"（3–6 人、RM 100–200 万 ARR），不是 VC 故事——接受这个定位再开始。
2. **怎么投**：资金（3 个月 RM 8–12 万）+ 时间（增长/BD 半职）+ 资源（中介网络）。
3. **12 个月目标选哪档**：保守 300 付费 / 基准 500 / 进取 800 —— 决定招聘与预算节奏。
